# @chaos_team/admin-ui-react

Typed React bindings for `@chaos_team/admin-ui-core`.

```tsx
import { AdminButton, AdminPage } from "@chaos_team/admin-ui-react";

<AdminPage title="Channels">
  <AdminButton variant="primary">Deploy New</AdminButton>
</AdminPage>;
```

Install the core package alongside this adapter:

```bash
bun add @chaos_team/admin-ui-react @chaos_team/admin-ui-core
```
